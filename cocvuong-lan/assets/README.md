# Bridge App Assets

This folder contains assets for the CocVuong Bridge Electron app.

## Required files:

- `icon.ico` - Windows icon (256x256)
- `icon.icns` - Mac icon (512x512)
- `icon.png` - PNG fallback (512x512)

## How to create icons:

1. Create a 512x512 PNG image
2. Use online tools like https://cloudconvert.com to convert:
   - PNG → ICO (for Windows)
   - PNG → ICNS (for Mac)
3. Place the files in this folder

## Recommended design:

- Bridge/connection symbol (🌉)
- CocVuong brand colors
- Clear and simple for small sizes
